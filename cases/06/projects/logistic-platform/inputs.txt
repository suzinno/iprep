Title: Логистическая платформа управления перевозками и аналитики

Description: Корпоративная платформа для управления заказами на перевозку, маршрутами, статусами доставки и взаимодействием с перевозчиками. Система консолидирует данные из внутренних и внешних источников, автоматизирует операционные процессы и формирует аналитические витрины для контроля эффективности логистики.

Environment: SQL, Python, Power BI, Tableau, PostgreSQL, Oracle, RabbitMQ, AWS(RDS, CloudWatch, S3, и др.), Jira, Confluence.

Responsibilities:
• Сопровождение изменений в отчётности при обновлении источников и структуры аналитических витрин;
• Формирование Source-to-Target Mapping для консолидации данных из транспортных и внутренних систем;
• Описание data lineage, структуры показателей и зависимостей между источниками и отчётными витринами;
• Разработка 15+ Data Marts для анализа перевозок, доставки, загрузки транспорта, SLA и операционной эффективности;
• Подготовка сложных SQL-запросов с CTE, оконными функциями и агрегациями для расчёта логистических показателей;
• Разработка дашбордов в Power BI и Tableau для мониторинга доставки, затрат, SLA и ключевых операционных KPI;
• Автоматизация ежедневной консолидации и подготовки больших объёмов транспортных данных с использованием Python;
• Реализация Python-проверок для сверки данных между источниками, аналитическими витринами и итоговой отчётностью;
• Настройка контроля качества данных: полнота, уникальность, корректность справочников и контроль расхождений;
• Проведение reconciliation по заказам, маршрутам, статусам доставки и расчётным показателям;
• Анализ и оптимизация унаследованных SQL-запросов PostgreSQL для операционной и аналитической отчётности;
• Оптимизация структуры PostgreSQL-витрин и запросов для ускорения формирования регулярных отчётов;
• Использование Oracle для анализа гибких данных, поступающих от внешних транспортных систем;
• Подготовка данных для near-real-time отчётности через RabbitMQ и асинхронные процессы;
• Анализ расхождений между данными перевозчиков и внутренними системами, подготовка корректирующих решений;
• Тестирование отчётности после изменений источников, mapping-логики и расчётных правил;
• Автоматизация регулярных проверок и контрольных сверок на Python, сокращающая объём ручной работы;
• Участие в подготовке релизов аналитической отчётности и проверке показателей после внедрения изменений;
• Ведение задач и технической документации в Jira и Confluence.
