# Glossary

This file is the single owner of every abbreviation fact used in generated documents: what a term expands to, what it is for, and where its official source lives. `.claude/scripts/link-abbreviations.py` is the only thing that writes those facts into prose — it links the first eligible occurrence of a term per file and reports divergence under `--check` — so no document states an expansion by hand and none drifts from this table.
